# Tab Compass · 页罗盘

![Tab Compass 图标](assets/icons/icon128.png)

> Find and manage your open tabs.

Tab Compass 是一款本地运行的 Chrome 标签页管理扩展。

当页面散落在多个窗口、标题相似，或者你只记得“刚才看过”却找不到它时，页罗盘会根据最近访问、前台停留和实际交互帮你重新定位页面，同时提供搜索、置顶、聚合和重复页清理能力。

它只管理当前仍然打开的标签页，不是书签工具，也不会保存已经关闭页面的浏览历史。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| **最近在看** | 页面连续显示达到设定时长后进入列表，默认门槛为 5 秒。 |
| **停留排行** | 按页面在前台、且 Chrome 窗口处于焦点状态的时间排序。 |
| **工作排行** | 根据输入、剪贴板、文本选择、点击和滚动等可配置行为，识别持续工作的页面。 |
| **全局搜索** | 按标题、网址或域名搜索所有窗口中已打开的普通网页。 |
| **一键定位** | 自动聚焦页面所在窗口，并切换到目标标签页。 |
| **置顶页面** | 按 URL 固定重要页面，关闭并重新打开弹窗后仍然保留。 |
| **域名聚合** | 将同一域名的页面合并展示，汇总停留与工作时长，并按活跃度排序。 |
| **精确去重** | 清理相同 URL 的重复标签页；保留项优先参考最近工作、最近打开和最近查看时间。 |

## 个性化

- **浅色 / 深色主题**：默认跟随 Chrome 或系统主题，可通过弹窗右上角的太阳/月亮按钮手动切换并记住选择。
- **自定义工具栏图标**：支持上传 PNG、JPG、WebP 或 SVG，图片会居中裁切并规范为 `128 × 128`。
- **展示数量**：每个分组可展示 1-10 个页面。
- **站点过滤**：支持域名白名单和黑名单；黑名单优先于白名单。
- **工作行为配置**：可独立开启键盘输入、剪贴板、文本选择、点击和滚动，并设置点击达到多少次后计入工作。

自定义图标会更新 Chrome 工具栏和扩展菜单。`chrome://extensions/` 使用安装包中的静态默认图标，Chrome 不允许扩展在运行时修改。

## 统计口径

扩展提供两种统计方式：

- **过去 24h（默认）**：累计最近 24 小时的浏览器前台活跃时间。没有打开浏览器的空白时段不会占用统计窗口，适合长期不关机的设备。
- **北京时间今日**：从北京时间当天 `00:00` 开始累计，到次日 `00:00` 重置。

其他规则：

- 只有 Chrome 窗口获得焦点、页面位于前台时才累计停留时间。
- “最近在看”的连续显示门槛可设置为 1-60 秒。
- 工作时间从当前连续浏览会话中首次出现有效工作行为后开始累计，切换页面或 Chrome 失去焦点后结束。
- 内容脚本最多每 15 秒上报一次交互信号，避免高频事件造成额外开销。
- 已关闭标签页会立即从扩展状态中移除，不再参与搜索、排序、聚合或统计。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `chrome-tab-compass` 文件夹。
5. 建议将 Tab Compass 固定到浏览器工具栏。

更新代码后，在扩展卡片上点击“重新加载”。如果更新涉及页面交互识别，还需要刷新已经打开的网页，使新版内容脚本生效。

## 使用方式

1. 正常浏览页面，并让目标页面在前台停留至少 5 秒。
2. 点击工具栏中的 Tab Compass 图标。
3. 从“最近在看”“过去 24h 停留”或“过去 24h 工作”中选择目标页面。
4. 输入关键词可搜索所有窗口中的已打开页面。
5. 使用“聚合”查看同域名页面，或使用“去重”清理相同 URL。
6. 点击页面右侧的置顶按钮，将常用页面固定到顶部。

点击弹窗右上角的齿轮可以调整统计口径、工作行为、展示数量、站点范围和自定义图标。

## 隐私与权限

所有状态和统计数据只保存在本机 Chrome 的扩展存储中，不会上传到服务器。

扩展需要：

- 读取当前打开的标签页，用于搜索、排序、切换、聚合和去重。
- 访问普通 HTTP/HTTPS 页面，用于识别前台页面中的有效交互。
- 使用本地扩展存储，保存统计状态、置顶页面和用户设置。
- 使用定时任务，在扩展后台周期性更新统计状态。

站点白名单和黑名单在本地执行。被过滤的页面不会进入统计或展示。

## 当前限制

- 仅处理 `http://` 和 `https://` 页面。
- 无法访问 `chrome://` 页面、其他扩展页面或未授权的本地文件。
- 不记录已关闭标签页，因此不能替代浏览历史、最近关闭或会话恢复工具。
- 自定义图标不能动态修改 `chrome://extensions/` 中显示的安装包图标。
- 浏览器休眠、扩展后台暂停或电脑关机期间不会累计时间。

## 开发验证

运行后台逻辑测试：

```powershell
node .\tests\service_worker.test.cjs
```

建议重点验证：

1. 在多个窗口中打开页面，确认搜索和一键定位正常。
2. 切换浅色与深色主题，关闭并重新打开弹窗，确认选择被保留。
3. 分别测试滚动、输入、复制和点击是否按设置计入工作时间。
4. 开启域名聚合，确认同域名时长正确汇总。
5. 打开多个相同 URL，确认去重保留最近使用的页面。
6. 修改白名单和黑名单，确认被过滤页面不再展示或统计。
