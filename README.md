# Tab Compass

页罗盘，`Find and manage your open tabs`。

Tab Compass 是一个本地 Chrome 扩展，用来快速定位已经打开、但散落在多个窗口中的页面。它不是“再开一个标签页”，而是帮你把已经打开过、刚刚用过、却一时找不到的那个页面重新找回来。

## 品牌表达

- 英文名：`Tab Compass`
- 中文名：`页罗盘`
- 产品宣言：`Find and manage your open tabs`

## 功能

- **最近在看**：页面连续显示超过 5 秒后，才会进入最近列表。
- **今日停留**：统计页面在前台且 Chrome 窗口处于焦点状态的时间。
- **今日工作**：前台页面近期发生点击、输入、滚动、复制、选择文本等交互时累计。
- **搜索**：按标题、网址或域名搜索全部已打开页面。
- **域名聚合**：点击“聚合”后，同域名页面合并，时长求和并按活跃度排序。
- **置顶**：将重要页面固定在插件顶部；Pin 按 URL 保存，浏览器重启后仍有效。
- **一键定位**：自动聚焦目标窗口并切换到目标标签页。

## 统计口径

- 日期固定按北京时间 `Asia/Shanghai` 切换，不受电脑时区或 VPN 影响。
- 只处理普通 `http://` 和 `https://` 页面。
- “最近在看”的默认门槛是连续显示 5 秒，可在设置页调整。
- “今日工作”的默认交互有效窗口是 2 分钟，可在设置页调整。
- 已关闭标签页会从插件状态中删除，不再参与搜索、排序或聚合。
- 所有数据只保存在本机 Chrome 的扩展存储中，不会上报。

## 工作行为

当前将以下行为视为工作活动，不区分权重：

- 点击和指针按下
- 键盘输入、表单输入和表单变更
- 粘贴、复制和剪切
- 页面滚动
- 文本选择变化

## 安装或更新

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 首次安装时点击“加载已解压的扩展程序”，选择 `chrome-tab-compass` 文件夹。
4. 已经安装时，在扩展卡片上点击“重新加载”。
5. 重新加载后刷新已经打开的网页，使新版内容脚本生效。

## 设置

点击弹窗右上角的齿轮，可调整：

- 每个分类展示数量
- “最近在看”的最短连续显示秒数
- 工作行为有效窗口
- 域名白名单和黑名单

白名单留空表示允许全部普通网页。黑名单优先于白名单。填写 `example.com` 会同时匹配 `example.com` 和它的子域名。

## 权限说明

扩展需要访问普通 HTTP/HTTPS 页面，才能识别任意已打开页面上的交互行为。权限不包含 `chrome://` 页面、其他扩展页面或本地文件。站点过滤在扩展后台执行，被过滤的页面不会进入统计或展示。

## 验证建议

1. 打开多个窗口和标签页，在某个页面停留至少 5 秒。
2. 在文档或表格页面输入、点击或滚动。
3. 打开插件，检查“最近在看”“今日停留”“今日工作”。
4. 搜索页面标题，并尝试开启“聚合”模式。
5. 置顶一个页面，关闭并重新打开弹窗，确认它仍在顶部。
6. 关闭某个标签页，确认它不再出现在搜索结果中。
